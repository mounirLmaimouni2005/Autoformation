# SPA && MPA

---
# 1. What is an SPA ?
  **SPA** means a Single-Page Application.

  - It usses one main HYML page.
  - The content changes without a full page reload
  - it often provides a smooth user experience 
 
 **Example :** Gmail__opning emails can update the content without reloading the whole page.

---
 # 2. What is an MPA ?
 **MPA** means Multi-Page Application.
 - It has a multiple pages.
 - Navigation usually loads a new HTML document.
 -Each page can have its own content.
 **Example :** A traditional website with Home , About , and contact pages.

 ---
 # 3. SPA vs MPA: Small Examples
  ### SPA example:
  A user clicks "Products". The application updates the content without a full page reload.
  ### MPA example:
  A user clicks "About". The browser loads a new HTML document for the About page.

  ---
  # 4. Conclusion 
  - SPA: One main page, updated content.
  - MPA: Multiple pages, usually with new document loads.
  - React: Often used to build SPAs.
